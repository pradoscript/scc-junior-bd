Como executar
================================================================

1. Pre-requisitos:
   - Docker + Docker Compose instalados
   - Python 3.10+

2. Configurar o ambiente:
   $ cp .env.example .env
   Abra o .env e ajuste a senha se desejar (campo POSTGRES_PASSWORD).

3. Subir os servicos (Postgres + Ollama):
   $ docker compose up -d
   O Postgres ja executa o DDL (sql/05.DDL.sql) e o DML (sql/06.DML.sql)
   automaticamente na primeira subida.

4. Baixar o modelo do Ollama no container (apenas uma vez):
   $ docker exec -it copa_ollama ollama pull llama3.2
   Aguarde o download (~2 GB). Para confirmar que foi baixado:
   $ docker exec copa_ollama ollama list

5. Instalar as dependencias do prototipo:
   $ cd prototipo
   $ pip install -r requirements.txt

6. Executar o prototipo:
   $ python main.py
   Use os defaults do .env ou informe manualmente quando solicitado:
   host=localhost, porta=5432, banco=copa_do_mundo,
   user=copa_admin, senha=<sua_senha>.

================================================================
Observacoes
================================================================
- O DDL define 5 triggers, 7 dominios e todas as FKs com ON DELETE/UPDATE.
- O DML cobre as Copas de 2018 (Russia) e 2022 (Catar) com resultados
  reais do mata-mata. A fase de grupos usa placares aleatorios determinisicos
  (seed fixa em scripts/gerar_dml.py).
- As 10 consultas estao implementadas em prototipo/queries.py.
- O item 11 do menu usa Ollama (rodando via Docker) para traduzir portugues
  em SQL. O modelo precisa ser baixado uma vez com o comando do passo 4.
  Se o servico estiver fora do ar, o programa avisa e segue funcionando.
